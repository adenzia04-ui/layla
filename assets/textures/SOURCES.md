# Earth textures

| File | Source | Licence |
|---|---|---|
| `earth_day.jpg` | NASA Visible Earth — Blue Marble | Public domain |
| `earth_night.png` | NASA Earth Observatory — Black Marble (city lights) | Public domain |

Both obtained via the three.js examples texture set, which redistributes NASA
imagery. NASA imagery is not copyrighted; no attribution is legally required,
but it is good manners and the credit line is "NASA Visible Earth".

The night texture is downscaled to 1024×512 — city lights are sparse points on
black and lose nothing at half resolution, and it halves the bundle cost.
